# Hospital — Талоны в поликлинику

## Description
Hospital — мобильное приложение для самостоятельной записи пациентов к врачам городских поликлиник. Приложение позволяет зарегистрироваться, выбрать поликлинику и специалиста, записаться на удобную дату/время, а также управлять существующими талонами (отмена, перенос). Поддерживаются русский, белорусский и английский языки.

## Installation

1. Склонировать репозиторий:
```
git clone https://github.com/DanikZorin/tpmp-lab9
```
2. Открыть папку проекта в Xcode 12+
3. Нажать `Cmd + R` для сборки и запуска

## Usage

1. **Регистрация:** Заполните форму (логин, пароль, ФИО, дата рождения, выберите поликлинику)
2. **Вход:** Используйте логин и пароль для входа в систему
3. **Запись:** Перейдите в раздел «Запись» → выберите поликлинику → врача → дату и время → нажмите «Записаться»
4. **Мои талоны:** Просматривайте активные записи, отменяйте или переносите их
5. **Профиль:** Редактируйте данные, меняйте язык интерфейса (RU/BY/EN) или выходите из системы
